### Destaques

**Automação de extração de documentos · Bradesco** *(código interno, não público)*<br>
Sistema em Python que lê documentos de operações de crédito rural, separa as garantias por tipo (hipoteca, alienação fiduciária, penhor), extrai os campos de cada uma e gera os dados e minutas consumidos por uma planilha Excel/VBA. Empacotado como executável com PyInstaller e usado pela equipe em rede.<br>
`Python` `PyMuPDF` `Regex` `Excel/VBA` `PyInstaller`

**Central de Atendimento · Estruturas de Dados (Mackenzie)**<br>
Projeto em grupo em Java: sistema de gestão de atendimento com fila circular e pilha implementadas sobre arrays, sem Java Collections. Arquitetura em camadas (`model`, `service`, `estruturas`, `ui`) pensada para trocar as estruturas por listas encadeadas sem mexer na interface.<br>
`Java` `Estruturas de Dados` `POO`

**Métodos numéricos · Algoritmos Numéricos (Mackenzie)**<br>
Implementação em Python de métodos para sistemas lineares, como Gauss e Jacobi.<br>
`Python` `Cálculo Numérico`
